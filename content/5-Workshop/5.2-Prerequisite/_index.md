**Accounts**
- An AWS account.
- A GitHub account and a repository that contains the source code (the project folder must be the repository root).
- A real email address that you own, used as `SenderEmail` for SES.

**Tools**
- Node.js 22.13 or later and pnpm 11.25.0 (can be enabled with Corepack).
- AWS CLI v2 and AWS SAM CLI.

**Permissions**
- Permissions for CloudFormation, IAM, DynamoDB, S3, Cognito, SES, Lambda and API Gateway.
- Allow SAM to create IAM roles when it asks.

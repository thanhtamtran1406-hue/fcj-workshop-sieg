# Deploy a Secure Restaurant Website with AWS Amplify

#### Overview

In this workshop you will deploy a restaurant website to **AWS Amplify Hosting**, connect it to a Git repository for automatic builds (CI/CD), and apply basic security hardening such as HTTPS, security headers, and least-privilege IAM.

Live demo of the group project: https://main.d2rkhtb7c0k5r7.amplifyapp.com/

# Triển khai website nhà hàng an toàn với AWS Amplify

#### Tổng quan

Trong workshop này bạn sẽ triển khai website nhà hàng lên **AWS Amplify Hosting**, kết nối với Git repository để tự động build và deploy (CI/CD), đồng thời áp dụng các biện pháp bảo mật cơ bản như HTTPS, security headers và IAM theo nguyên tắc đặc quyền tối thiểu.

Bản demo của dự án nhóm: https://main.d2rkhtb7c0k5r7.amplifyapp.com/
